# 易服道（YiFuDao）请假小程序

基于 [Eoyz369/WeChat_YiFuDao](https://github.com/Eoyz369/WeChat_YiFuDao)（AGPL-3.0）二次开发的微信请假管理小程序，在保留原有请假/审批流程的基础上，扩展了多项自定义与体验优化功能。

## 功能特性

- **请假申请**：自定义学院、班级、审批人，表单自动记忆回填上次填写内容
- **出入校二维码**：展示学院与个人信息
- **班级成员管理**：添加/删除成员、修改姓名/手机号、设置/撤销班干
- **自定义头像**：点击头像可从相册上传，也可一键使用微信头像
- **首页轮播图**：自定义上传、长按删除、恢复默认图
- **假条详情**：长按修改申请/审批时间，支持销假，状态区分（休假中/已结束）
